# /tif:catalog

Run the catalog script with the user's arguments and relay its output unchanged.

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/scripts/tif.py" $ARGUMENTS
```

If no arguments were given, run it with `help`.

Run exactly that command and nothing else: do not append other commands (such as echoing the exit code) or pipe the output.

Do not read, search or summarize the catalog files yourself; the script is the only source of catalog information. Report its output as printed, including warnings, and report a non-zero exit as a failure. Do not edit installed files afterwards unless the user asks.
